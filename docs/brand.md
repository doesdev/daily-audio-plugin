# The brand

The name is **Daily Audio Plugin**, written **DAP** where it is short.
It ships everywhere a plugin does, and it is said one way.

- A host shows the maker as `Daily Audio Plugin` (`kit::VENDOR`,
  which every plugin's `Info` uses). Hosts find plugins by their ids,
  which have not changed and never do, so a project made before the
  name still opens.
- In words, a plugin is "Undertow, a Daily Audio Plugin" once, and
  "DAP" after. "DAP plugin" says plugin twice: say "DAP instance" for
  one that is open, "a DAP effect" or "a DAP instrument" for a kind.
- The editor says it where the name is: pointing at a plugin's name
  says it is one of DAP's. Linking is offered between "DAP instances"
  because it works across all of them and nothing else.
- A manual and a release say it once, in their first line.
- The folder a person's presets live in is still `doesdev`
  (`kit::HOME`). It is the name the first releases used, and moving it
  would strand what people have saved.

Not decided: a drawn mark. The editor has none, since how DAP looks
is chosen on the design canvas before it is built, as the rest of
the look was. Until then the name set in the house face is the mark.

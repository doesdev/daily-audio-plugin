# Aftersound: what changed

## 0.2.4 (2026-11-28)

- Fixed: after its notes died away it went on costing about eight
  times what playing did, for as long as it was left. A quiet
  instance now costs less than a playing one.

## 0.2.3 (2026-11-28)

- When linking, other instances are listed by the track they are on,
  as in "Drum Bus, Undertow", where the host tells a plugin its track.

## 0.2.2 (2026-11-27)

- The DAP mark is at the top left of the editor, with the name under
  it.

## 0.2.1 (2026-11-27)

- Hosts file it as a synth. In Cubase it was under "Other".

## 0.2.0 (2026-11-27)

- Any setting can be linked to the same setting in other DAP
  instances: right-click it.
- Fixed: in some hosts every setting went back to its default when a
  project was reopened.
- Fixed: a right-click on an empty part of the editor no longer opens
  a browser menu.
- The maker shows in hosts as Daily Audio Plugin.

## 0.1.0 (2026-11-26)

- First release: an instrument in which every note is two coupled
  strings, one in each channel.
